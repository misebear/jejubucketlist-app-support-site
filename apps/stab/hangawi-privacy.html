한가위 가족오락실 개인정보처리방침

적용 대상: STAB! Android 1.8.0의 한가위 가족오락실 및 함께 제공되는 기존 놀이. 갱신일: 2026년 9월 27일.

이 버전의 필수 놀이는 회원가입 없이 기기에서 실행됩니다. 광고·Firebase Analytics·UMP 네이티브 SDK와 광고 ID 권한을 포함하지 않습니다. 이미 배포된 이전 STAB! 버전의 광고·분석 안내는 기존 버전 방침을 확인하세요.

연령과 이용

생년월일 대신 연령대를 기기에 저장합니다. 13세 미만은 앱 이용을 차단합니다. 13~17세의 분석 제한을 유지하며, 이 버전은 가족 놀이에서 원격 분석을 사용하지 않습니다.

기기에 저장되는 정보

팀 이름·인원·경기 상태·결과·직접 만든 문제팩·설정은 기기에 저장됩니다. 기존 STAB!에서 사용자가 보관한 얼굴 사진·파티 설정·구매 정보는 한가위 놀이를 추가해도 지우지 않습니다. 얼굴 사진은 앱 전용 저장소에 보관되고 Android 백업에서 제외됩니다.

공유와 외부 전송

기본 도전 코드와 결과 카드에는 개인 이름·사진·직접 만든 문제 내용을 넣지 않습니다. 사용자가 백업 파일을 내보내면 직접 입력한 팀 이름과 문제 내용이 포함될 수 있습니다. 사용자가 Android 공유창에서 앱이나 수신자를 선택하면 해당 수신 서비스의 방침에 따라 자료가 전달될 수 있습니다. 앱은 전달 완료나 상대방의 열람 여부를 확인하지 않습니다.

권한과 네트워크

Android 앱은 인터넷, 네트워크 상태, 진동 권한을 선언하며 카메라·저장소·위치 runtime permission을 새로 요청하지 않습니다. 필수 한가위 놀이는 설치 후 오프라인으로 시작할 수 있습니다. 웹은 첫 방문에 인터넷이 필요하고, 호스팅 사업자가 접속 로그를 처리할 수 있습니다. 외부 링크와 Google Play의 인앱 리뷰는 해당 서비스로 이동할 때만 사용됩니다.

삭제와 문의

앱의 ‘한가위 데이터 삭제’는 한가위 팀·경기·문제팩·설정만 삭제하고 기존 STAB! 사진·구매·설정은 보존합니다. 기기 설정에서 앱 데이터를 지우거나 앱을 제거하면 기기의 앱 데이터가 삭제됩니다. 개인정보 문의: db0192a@gmail.com.
